Catálogo de prueba para GitHub Pages.

Descomprime el ZIP y sube TODO su contenido a la raíz del repositorio (index.html, styles.css, app.js, products.json y assets/). En GitHub: Settings > Pages > Deploy from a branch > main > / (root).

Incluye búsqueda, filtros y selección guardada en el navegador. No envía pedidos, no procesa pagos, no guarda pedidos en un servidor. El total y las fotos provienen de las capturas; revisa los precios antes de publicar.

GitHub Pages es para esta versión de prueba. Su política no permite alojar allí una tienda centrada en transacciones comerciales. Para ventas reales puedes conservar este mismo repositorio y publicarlo con un alojamiento que permita uso comercial.
